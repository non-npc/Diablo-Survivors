# Distribution boundaries

Ship authored engine/editor/inspector code, original demo resources, schemas, reviewed metadata profiles/catalogs and documentation. Ship no original game assets, proprietary executables, archive payloads or normalized derivatives. Local extraction files are excluded from version control and packages. The source packager excludes `.tools` and `.local`; filename scanning is an additional guard, not a full license/content audit.

Use only user-supplied local installations. Do not bypass access controls or execute extracted scripts/binaries. Review parser/dependency licenses before bundling binaries. Record provenance for each local resource. There is no cloud service, telemetry or upload. Do not imply Blizzard endorsement or original-save compatibility.
