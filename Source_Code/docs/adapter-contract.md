# Adapter contract

See `adapters/base/contract.py` for detect, inspect, enumerate_assets, extract, normalize, suggest_mappings, validate and get_capabilities. Implementations must declare editions explicitly and return schema-validated metadata. A filename/hash match is distinct from validated payload decoding, animation mappings and a playable campaign.

Current MPQ services are shared inspector primitives, not complete game adapters. The administrator catalog stores archive fingerprint-bound block offsets/sizes/flags. Do not apply offsets to an archive with a different identity. Draft profiles remain `inspected` until local tests cover the claimed capabilities. Earlier non-GOG editions need their own evidence.
